审计证据管理系统
Audit Evidence Platform

让每一条审计证据
都有来处，也有去处

项目—事项—证据三级归属，编制与复核强制分离，每一次状态变更都留痕可追溯。 这不是一个增删改查的练习项目，而是按审计实务的底稿逻辑搭起来的执行平台。

01
三级归属　审计项目 → 审计事项 → 审计证据，对齐底稿编制习惯
02
状态机管控　草稿 → 待复核 → 已确认 / 已驳回，非法流转直接拒绝
03
编制复核分离　提交人不能复核自己的证据，这是准则的硬要求
Spring Boot 3.5 · MyBatis-Plus · MySQL 8 · Redis
